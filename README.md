# Планировщик бухгалтера

Программа для Windows 11: план задач на день по всем клиентам, сроки отчётов и платежей, напоминания.
Работает на этом компьютере и никуда не отправляет данные клиентов.

## Установка (первый раз)

1. Откройте [страницу последней версии](https://github.com/AlexanderTishchenko/accountant-planner-releases/releases/latest)
   и в разделе **Assets** скачайте файл `BuhPlanner-Setup-X.Y.Z.exe`.
   Если браузер пишет, что файл «обычно не скачивают», выберите «Сохранить» («Всё равно сохранить»).
2. Запустите скачанный файл. Windows может показать синее окно **«Windows защитила ваш компьютер»**
   (SmartScreen): у программы нет платного сертификата подписи, и Windows её «не знает».
   Нажмите **«Подробнее»** → **«Выполнить в любом случае»**. Права администратора не нужны.
3. Отметьте, запускать ли программу при входе в Windows и нужен ли значок на рабочем столе,
   и нажмите «Установить». Программа откроется сама.

Программа живёт в трее — у часов в правом нижнем углу (значок может прятаться под стрелкой «^»).
Крестик окна её не выключает: напоминания продолжают приходить. Открыть окно — щелчок по значку в трее
или ярлык «Планировщик бухгалтера» в меню «Пуск». Выйти совсем — правой кнопкой по значку → «Выход».

## Первые шаги

- **Клиенты** → «Добавить клиента». Много клиентов удобнее загрузить из Excel: «Выгрузить в Excel»
  даст таблицу нужного вида, заполните её и нажмите «Загрузить из Excel».
- Задачи появляются сами — по правилам сроков (экран **«Правила»**) и производственному календарю
  (**Настройки → Нерабочие дни**).
- Свои повторяющиеся дела — экран **«Свои задачи»**, аренда и другие регулярные платежи — **«Платежи»**.

## Где хранятся данные и резервные копии

- Данные — только на этом компьютере, в папке `%LOCALAPPDATA%\BuhPlanner`.
- Резервные копии — в папке **Документы\Планировщик\Резервные копии**: каждый день (хранятся
  последние 30), а также перед обновлением программы, перед загрузкой из Excel и перед восстановлением.
  Папку можно сменить в **Настройках** — например, на флешку. Если «Документы» синхронизируются
  с OneDrive, копии кладутся в папку профиля пользователя, чтобы данные клиентов не уходили в облако.
- Вернуть данные из копии: **Настройки → Резервные копии → «Восстановить»** у нужной копии.
  Текущие данные перед этим сохраняются отдельной копией — ничего не пропадает безвозвратно.
- Если база данных не открывается, программа сама покажет причину и список копий.

## Обновления

- Программа сама проверяет обновления раз в сутки. Когда выйдет новая версия, вверху окна появится
  **«Доступно обновление X.Y.Z»**. Нажмите, прочитайте «Что нового» и нажмите **«Обновить сейчас»**:
  программа сделает резервную копию, закроется и примерно через минуту откроется уже новой версией.
  Данные и настройки остаются на месте.
- Проверить вручную: **Настройки → «Проверить обновления»**.
- Если после обновления что-то не так: **Настройки → «Вернуть предыдущую версию»**. Данные вернутся
  к копии, сделанной перед обновлением (изменения после обновления сохранятся отдельной копией).
  Если новая версия не запускается, программа сама предложит вернуть предыдущую.

## Если что-то пошло не так

**Настройки → «Сохранить диагностику»** — откроется папка с файлом `diagnostics_….zip`. В нём журналы
программы и копия базы **с данными клиентов**: передавайте файл только разработчику, лично, и не
выкладывайте его в открытый доступ.

## Как устроены задачи

- «Сделано» → задача уходит в «Ждут проверки»; «Проверено» → в архив.
- Сроки налогов и отчётов — только по таблице правил. Правило можно поправить на экране «Правила»:
  обновления программы вашу правку не перезапишут, а спросят, что оставить.
- Если срок выпадает на выходной, он переносится по правилу (обычно на следующий рабочий день);
  выплата зарплаты и аванса — на предыдущий рабочий день.

Договорённости, которые можно поменять в программе:

- отдельные напоминания о сроках без точного времени выключены — есть утренняя сводка
  (включаются в «Настройках»);
- в чек-листах невыполненное с прошлой недели не переносится (переключатель на экране «Чек-листы»);
- свои задачи повторяются разово, ежемесячно, ежеквартально или ежегодно;
- платёж в выходной — на предыдущий рабочий день, показывается за 3 дня, сумма необязательна
  (всё меняется в карточке платежа).

## Удаление

Параметры Windows → Приложения → «Планировщик бухгалтера» → «Удалить». Данные и резервные копии
остаются; если они не нужны, удалите вручную папку `%LOCALAPPDATA%\BuhPlanner`
и папку **Документы\Планировщик**.
